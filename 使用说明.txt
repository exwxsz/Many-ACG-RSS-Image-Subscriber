【怎么用】(三步搞定)
--------------------------------------------------------
第 1 步：直接双击运行  dist\RSS图片订阅.exe
         无需安装 Python，无需安装任何依赖，全部已内嵌。

第 2 步：首次运行会在下面位置自动生成配置文件
         %USERPROFILE%\.manyacg_get\config.json

         ★ 重要提示 ★
         程序默认图片保存目录是  D:\图片
         如果你的电脑没有 D 盘，请先点「设置」把保存目录改成
         其他位置（例如 E:\图片 或 C:\Users\你的用户名\Pictures），
         否则下载会失败。

第 3 步：在左侧「订阅」里添加/编辑 RSS 订阅源，
         然后点开始爬取即可。下载的始终是主站原图(jpg/png)，
         而不是 RSS 里 CDN 压缩过的 webp 缩略图。

【目录说明】
--------------------------------------------------------
  dist\RSS图片订阅.exe     主程序（已打包，双击运行）
  main.py                  源码入口（需 Python 环境）
  requirements.txt         Python 依赖清单
  build.bat                自行重新打包 EXE 的脚本
  使用说明.txt             本文件

  core\                    核心业务逻辑（无 UI 依赖，可独立测试）
    config_manager.py        配置管理
    database_manager.py      JSON 数据库（去重/断点/删除标记）
    rss_parser.py            RSS/Atom 解析
    manyacg_api.py           主站 API 客户端（原图获取）
    site_adapters.py         无 RSS 站点适配器框架
    html_extractor.py        无 RSS 提取入口
    image_downloader.py      并发下载器

  ui\                      PySide6 界面代码
  assets\app.ico           应用图标
  docs\ARCHITECTURE.md     架构与数据流说明
  tests\                   测试脚本（开发者用）
  dev\                     开发期站点分析草稿（可忽略）

【安全与隐私说明】
--------------------------------------------------------
  * 本程序不收集、不上传任何用户数据（无遥测、无统计上报）
  * 源码中不含任何账号、密码、API Key 或 Token
  * 全程无需登录，程序不要求也不存储任何账号口令
  * HTTP 请求仅携带常规 User-Agent，无 Cookie、无 Authorization
  * 所有数据仅保存在本机：
      %USERPROFILE%\.manyacg_get\config.json     配置
      %USERPROFILE%\.manyacg_get\database.json   索引
      以及你自己指定的图片保存目录
  * 删除 %USERPROFILE%\.manyacg_get\ 目录即可彻底清除全部痕迹
  * dist 下的 EXE 由本仓库 build.bat 通过 PyInstaller 本地构建，
    可由 build.bat 复现，也可直接用源码运行

  ⚠ 请优先从上面「项目主页」的 Releases 页面获取压缩包，
    其他渠道的文件请自行校验后再运行。
